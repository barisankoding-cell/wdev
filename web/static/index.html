Buat Virtual Host Baru (wdev site create)

Ekspos ke VPS Edge Gateway

Ekspos vhost lokal (PHP/Laravel/WordPress) atau port aplikasi lokal (Node.js/Go/Python/Docker) ke internet melalui VPS Edge Gateway dengan otomatisasi DNS dan SSL Let's Encrypt.

Deploy & Install VPS Edge Gateway

Instalasi otomatis PowerDNS Authoritative, SQLite3, Nginx Reverse Proxy, dan Edge Agent ke VPS Anda via SSH. Konfigurasi dan API key otomatis disinkronkan ke mesin lokal.

Disarankan menggunakan IP NetBird mesh agar jalur manajemen terenkripsi aman.

Hubungkan Manual ke VPS Edge

Gunakan ini jika VPS sudah terpasang PowerDNS & Edge Agent sebelumnya. Masukkan kredensial dari /etc/wdev-edge/edge.conf di VPS.

Masukkan API Key Resend. Kosongkan saat mengubah relay yang sudah ada untuk memakai key tersimpan.

Setup Domain & Mail Server Baru

Mengonfigurasi otomatis engine Stalwart lokal, webmail SnappyMail, record DNS (A, MX, SPF, DMARC) di VPS Edge, serta reverse-proxy SSL Let's Encrypt.
Sistem otomatis mendeteksi Zone DNS yang tersedia di PowerDNS VPS Edge Gateway untuk konfigurasi Stalwart, SnappyMail & DNS Record.
⚠️ Belum ada Zone DNS terdaftar di VPS Edge PowerDNS. Tambahkan zone di tab PowerDNS terlebih dahulu, atau ketik domain manual di atas jika zone baru saja ditambahkan.
Mode relay-only: email keluar tidak pernah dikirim langsung via port 25. Pilih relay atau warisi relay default.
